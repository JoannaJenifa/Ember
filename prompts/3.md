## Part A: TipJar Module

### Create sources/tip_jar.move

**Structs:**
```move
struct Tip has store, drop, copy {
    id: u64,
    sender: address,
    streamer: address,
    amount: u64,
    message: String,
    timestamp: u64,
}

struct TipJar has key {
    tips: SmartTable<u64, Tip>,
    streamer_tips: SmartTable<address, vector<u64>>,
    streamer_total: SmartTable<address, u64>,
    tip_count: u64,
    platform_fee_bps: u64,  // 5% = 500 bps
    fee_recipient: address,
}
```

**Entry functions:**
- `initialize(admin: &signer, fee_recipient: address)`
- `send_tip(sender: &signer, streamer: address, amount: u64, message: String)`

**View functions:**
- `#[view] get_tip(tip_id: u64): Tip`
- `#[view] get_streamer_tips(streamer: address, limit: u64): vector<Tip>`
- `#[view] get_streamer_total(streamer: address): u64`
- `#[view] get_recent_tips(limit: u64): vector<Tip>`

**Payment flow:**
```move
// send_tip:
// 1. Verify amount > 0
// 2. fee = amount * 500 / 10000 (5%)
// 3. streamer_amount = amount - fee
// 4. Transfer streamer_amount to streamer
// 5. Transfer fee to fee_recipient
// 6. Create tip record, update totals
```

**Events:** TipSent

## Part B: GiftShop Module

### Create sources/gift_shop.move

**Structs:**
```move
struct Gift has store, drop, copy {
    id: u64,
    sender: address,
    streamer: address,
    gift_type: GiftType,
    quantity: u64,
    total_value: u64,
    message: String,
    timestamp: u64,
}

struct GiftShop has key {
    gifts: SmartTable<u64, Gift>,
    gift_prices: SmartTable<u8, u64>,  // gift_type -> price
    streamer_gifts: SmartTable<address, vector<u64>>,
    streamer_earnings: SmartTable<address, u64>,
    gift_count: u64,
    platform_fee_bps: u64,  // 10% = 1000 bps
    fee_recipient: address,
}
```

**Default gift prices (set in initialize):**
```move
// Heart: 1 MOVE (1_0000_0000)
// Star: 5 MOVE
// Fire: 10 MOVE
// Diamond: 50 MOVE
// Crown: 100 MOVE
```

**Entry functions:**
- `initialize(admin: &signer, fee_recipient: address)` - Set default prices
- `set_gift_price(admin: &signer, gift_type: u8, price: u64)`
- `send_gift(sender: &signer, streamer: address, gift_type: u8, quantity: u64, message: String)`

**View functions:**
- `#[view] get_gift(gift_id: u64): Gift`
- `#[view] get_gift_price(gift_type: u8): u64`
- `#[view] get_all_gift_prices(): vector<(u8, u64)>`
- `#[view] get_streamer_gifts(streamer: address, limit: u64): vector<Gift>`
- `#[view] get_streamer_earnings(streamer: address): u64`

**Payment flow:**
```move
// send_gift:
// 1. Get price from gift_prices
// 2. total = price * quantity
// 3. fee = total * 1000 / 10000 (10%)
// 4. streamer_amount = total - fee
// 5. Transfer amounts
// 6. Create gift record
```

**Events:** GiftSent
