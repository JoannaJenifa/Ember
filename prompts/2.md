## Part A: OrderEscrow Module

### Create sources/order_escrow.move

**Structs:**
```move
struct Order has store, drop {
    id: u64,
    buyer: address,
    seller: address,
    product_id: u64,
    quantity: u64,
    total_price: u64,
    platform_fee: u64,     // 3% fee
    seller_amount: u64,
    status: OrderStatus,
    shipping_info: String,
    created_at: u64,
    shipped_at: u64,
    delivered_at: u64,
}

struct OrderEscrow has key {
    orders: SmartTable<u64, Order>,
    buyer_orders: SmartTable<address, vector<u64>>,
    seller_orders: SmartTable<address, vector<u64>>,
    order_count: u64,
    auto_release_days: u64,
}
```

**Entry functions:**
- `initialize(admin: &signer, auto_release_days: u64)`
- `create_order(buyer: &signer, product_id: u64, quantity: u64, shipping_info: String)` - Transfer MOVE to escrow
- `mark_shipped(seller: &signer, order_id: u64)`
- `confirm_delivery(buyer: &signer, order_id: u64)` - Release funds to seller
- `dispute_order(buyer: &signer, order_id: u64)`
- `resolve_dispute(admin: &signer, order_id: u64, refund_buyer: bool)`
- `cancel_order(buyer: &signer, order_id: u64)` - Refund before shipped

**View functions:**
- `#[view] get_order(order_id: u64): Order`
- `#[view] get_buyer_orders(buyer: address): vector<u64>`
- `#[view] get_seller_orders(seller: address): vector<u64>`
- `#[view] has_delivered_order(buyer: address, product_id: u64): bool`

**Payment flow:**
```move
// create_order:
// 1. Verify product exists, has inventory
// 2. total = price * quantity
// 3. fee = total * 300 / 10000 (3%)
// 4. Transfer MOVE from buyer to escrow
// 5. Decrement product inventory
// 6. Create order

// confirm_delivery:
// 1. Verify status == Shipped
// 2. Transfer seller_amount to seller
// 3. Transfer platform_fee to fee_recipient
// 4. Update seller stats
// 5. status = Delivered
```

**Events:** OrderCreated, OrderShipped, OrderDelivered, OrderDisputed

## Part B: ReviewRegistry Module

### Create sources/review_registry.move

**Structs:**
```move
struct Review has store, drop, copy {
    id: u64,
    order_id: u64,
    product_id: u64,
    reviewer: address,
    seller: address,
    rating: u64,          // 1-5
    content: String,
    is_verified: bool,    // Always true (verified purchase)
    created_at: u64,
}

struct ReviewRegistry has key {
    reviews: SmartTable<u64, Review>,
    product_reviews: SmartTable<u64, vector<u64>>,
    user_reviews: SmartTable<address, vector<u64>>,
    order_reviewed: SmartTable<u64, bool>,
    review_count: u64,
}
```

**Entry functions:**
- `initialize(admin: &signer)`
- `submit_review(reviewer: &signer, order_id: u64, rating: u64, content: String)`

**View functions:**
- `#[view] get_review(review_id: u64): Review`
- `#[view] get_product_reviews(product_id: u64): vector<Review>`
- `#[view] has_reviewed_order(order_id: u64): bool`
- `#[view] get_product_rating(product_id: u64): (u64, u64)` - (avg*100, count)

**Verification logic:**
```move
// submit_review:
// 1. Get order, verify status == Delivered
// 2. Verify order.buyer == signer
// 3. Verify !order_reviewed[order_id]
// 4. Create review (is_verified = true)
// 5. Update product rating
// 6. Update seller rating
// 7. Mark order reviewed
```

**Events:** ReviewSubmitted
